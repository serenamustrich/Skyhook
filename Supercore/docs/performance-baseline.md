# Supercore 性能基线

这是一组在 Apple Silicon macOS、Release 优化配置下的可重复基线。运行方式：

```bash
cargo bench --benches
```

基准代码位于 `Supercore/benches/`，使用固定规模输入，输出单次完整场景耗时，不代表真实网络吞吐。

| 场景 | 输入规模 | 本次基线 |
|---|---:|---:|
| 路由决策 | 1000 条规则 / 10000 次决策 | 1.544 s |
| Probe 调度建模 | 1000 个请求 | 93.8 us |
| Fake-IP 映射 | 10000 条域名 | 7.24 ms |
| SOCKS5 目标 framing | 10000 个目标 | 319.6 us |
| 订阅解析 | 1000 个节点 | 6.26 ms |

## 解释

- Probe 基准只测调度目标计数，不拨号网络；真实延迟应通过协议 probe 集成测试和同一订阅对比脚本评估。
- 路由基准使用线性规则列表，后续若要支持十万级规则，应增加编译索引并保留本基线作为回归参照。
- Fake-IP、framing 和订阅解析基准均不访问网络、不读取用户目录，也不包含真实订阅数据。
- Release LTO benchmark 首次构建约需 10 分钟；后续增量构建取决于改动范围。
